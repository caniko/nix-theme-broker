# Gruvbox native adapters

The Vim adapter uses the canonical `morhetz/gruvbox` implementation. The
Neovim adapter uses the pinned, maintained `ellisonleao/gruvbox.nvim` plugin.
The VS Code and Bibata cursor adapters are maintained native integrations. The
Chromium and Brave adapters build a permissionless, color-only Manifest V3 CRX
for Gruvbox dark-hard. All receive colors from the normalized provider
selection.
